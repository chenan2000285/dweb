# dweb

陈安的网页小仓库：纯 HTML / CSS / JS，单文件、无依赖、不联网也能跑。

在线地址：<https://chenan2000285.github.io/dweb/>

## 内容

| 路径 | 说明 |
| --- | --- |
| [`clicker/`](clicker/) | 开源点击游戏（index.html / game.js / scene.js / style.css） |
| [`toys/`](toys/) | 小玩意儿合集：星空引力、摩尔斯电报机、随机配色卡、今天去哪了 |

## 本地文件

改代码在手机的 `/sdcard/aiweb/` 里，用 MT 管理器编辑；推上线跑 `/root/workspace/update-dweb.sh`。

## 说明

GitHub Pages 由 `main` 分支根目录发布，push 后约 1 分钟生效。页面加了 `?v=xxx` 可以绕过旧缓存。
